PYCHARM PROJECT - BAI TAP BUOI 1, PHAN B - NHOM 01

Huong dan chay:
1) Mo folder btnhom trong PyCharm.
2) Tao hoac chon virtual environment Python 3.10 tro len.
3) Terminal: python -m pip install -r requirements.txt
4) Chuot phai vao main.py -> Run, hoac Terminal: python main.py
5) Doi den khi thay thong bao DONE. Cac output se gom:
     data/    - 6 anh goc va cac phien ban suy giam nhan tao
     results/ - CSV cua B1/B2/B3, bieu do B2, luoi anh B3, hinh that bai B4
     BaoCao_B1_Nhom01.pdf - bao cao 5 trang

- Kiem tra lai so nhom, ho ten, MSSV va phan tram dong gop trong config.py.
- Phan tram phai cong lai dung 100%.
- Nen doc lai B3 pipeline de xac nhan ket qua.
